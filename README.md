**RaidPolice** es el addon definitivo para líderes de banda en WotLK. Detecta y reporta automáticamente todo lo que arruina una raid.

📦 Instalación

**Opción 1 - GitHub (Recomendado):**
1. Descarga el .zip desde `Releases`
2. Extrae en `World of Warcraft/Interface/AddOns/`
3. Debe quedar `Interface/AddOns/RaidPolice/RaidPolice.toc`
4. `/reload` en juego

**




🎮 Comandos

Todos los comandos funcionan con `/rp` y `/RaidPolice`

/rp stats - Muestra estadísticas completas de la raid
/rp clear - Limpia todas las stats (nuevo intento)
/rp status - Estado de módulos
/rp help - Ayuda

💬 Mensajes en Raid

- **Manada:** `🐯 |cFFFF8000Seth|r ¡Quita Manada!`
- **Festin:** `🍗 FESTIN: Seth comio del festin! x1 ... x99`
- **First Hit:** `🎯 FIRST HIT: Seth ¡Pulleó a Sindragosa!`

Los nombres salen con **color de clase** automático.
